# ARCHITECTURE: gokulmobilize

Only what exists. Updated: 2026-10-31.

## HLD
```text
browser -> /apps (Astro static pages, base /apps)
  index.html: TileGrid (skeleton cards, then a vanilla-TS script)
     createConfigStore(url) --(1) read IndexedDB 'hub-config'--> emit cached tiles
                            --(2) fetch config.json (no-cache, ETag)--> parseHubConfig --> emit + save
                            --(3) refresh on visibilitychange / online
  [slug].astro: 9 footer pages (LegalPage from @gokulsaraswat/ui)
  Base.astro: tokens.css + styles.css + Footer (rendered at build time, no client React), manifest link, SW registration (prod only)
  sw.js (scope /apps/): Workbox precache of every built file; pages keyed by clean URL (/apps/faq); navigation fallback /apps/
```
config URL = `PUBLIC_HUB_CONFIG_URL`, or `/apps/config.mock.json` when unset.

## LLD
| File | Responsibility |
|---|---|
| `src/lib/hub-config.ts` | `createConfigStore(url, storage?, fetcher?)` -> `{ subscribe, load, refresh }`. Storage (`KeyValueStorage`, default idb-keyval) and fetch are injected for tests. Invalid or unreachable config never replaces a valid cached copy. |
| `src/lib/render-tiles.ts` | `renderTiles(grid, template, config, target?)`: enabled, reachable tiles only (via `resolveTileLink`); textContent only; browser-bound links get `data-open-in-browser` + new tab. |
| `src/lib/saved-items.ts` | `listSaved()` / `removeSaved(url)` over IndexedDB `gk-saved`/`items`, written by the portfolio. `toSavedList` validates (same-origin paths only) and sorts. |
| `src/components/SavedList.astro` | "Saved for later" section, hidden when empty; re-reads on visibilitychange. |
| `src/lib/tile-meta.ts` | Hub-only description and accent token per `AppId`. |
| `src/components/TileGrid.astro` | Markup, skeletons, status line, store wiring, scoped styles. |
| `src/layouts/Base.astro` | Head, global tokens, cross-document `@view-transition`, Footer, manifest, SW registration. |
| `scripts/build-sw.mjs` | Post-build: `workbox-build` `generateSW` over `dist/`; maps `page.html` to `/apps/page`. |
| `public/manifest.webmanifest`, `public/*.png` | PWA manifest; icons generated by `@vite-pwa/assets-generator` from the placeholder Astro favicon. |

## Size (production build, gzip)
- Tile script 24 KB. Most of it is zod, pulled in via `parseHubConfig`.
- React's client runtime is emitted but not loaded, because no component hydrates. The SW still precaches it (~200 KB raw of the 334 KB precache).

Astro `build.format: 'file'` (page.html) so the SW and Vercel `cleanUrls` serve `/apps/page`.

## Native app (Android, Capacitor 8.5)
```text
npm run build:native (PUBLIC_HUB_NATIVE=true): base '/', outDir dist-native, no SW, footer links via FileLink (/faq.html)
  + scripts/bundle-apps.mjs: dist-native/gspace|studio <- bundled/<id>/ or a placeholder page
cap sync android -> android/app/src/main/assets/public (gitignored) -> gradlew assembleDebug
WebView https://localhost/ : hub; bundled tiles -> /<id>/index.html; remote/external tiles -> Browser.open (Custom Tabs)
MainActivity: back = WebView history back on every page, else exit
```
| File | Responsibility |
|---|---|
| `src/lib/tile-target.ts` | `resolveTileLink(tile, { native, siteOrigin })`: link + whether to open in the browser; null hides the tile. |
| `src/components/FileLink.tsx` | Footer `linkComponent` for the app build: appends `.html`. |
| `capacitor.config.json` | appId, appName, `webDir: dist-native`. No `server.allowNavigation` (the docs mark it not for production). |
| `android/.../MainActivity.java` | Back-button handling through WebView history. |

## Release pipeline
`git tag vX.Y.Z && git push origin vX.Y.Z` -> CI `android-release`: decode `ANDROID_KEYSTORE_BASE64` to the runner temp dir -> `assembleRelease` (signing from env in `android/app/build.gradle`; versionName = tag, versionCode = run number) -> APK attached to the GitHub Release -> keystore deleted.
